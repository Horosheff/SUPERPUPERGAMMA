# План работ (MVP) — Vanilla ReAct Agent (Gemini)

## Контекст

- Репозиторий: Node.js + TypeScript агент в стиле ReAct, прямой `fetch` к Gemini API.
- Уже есть:
  - CLI (`src/index.ts`)
  - Оркестратор 5 агентов для слайдов (`src/orchestrator/*`)
  - Веб-сервер + UI под слайды (`src/server.ts`, `public/index.html`)
- MCP “Context 7”: в текущем окружении **нет подключённых MCP ресурсов**, поэтому поиск “готовых репозиториев”/примеров через MCP выполнить не удалось.

## Цель MVP

Сделать “песочницу” для агента, которая стабильно работает:

- **Web UI**:
  - Генерация 5 слайдов (уже есть) + безопасная отмена по закрытию вкладки
  - **Одноагентный режим** (вопрос → ReAct → ответ) из браузера
- **Надёжность**:
  - Устойчивый парсинг JSON-ответа модели (извлечение JSON-объекта даже при “лишнем” тексте)
  - Возможность остановить выполнение (AbortSignal) для экономии токенов/времени
  - Параметризация модели через env (`GEMINI_MODEL`, приоритет над дефолтом)
- **Документация**:
  - README с командами `dev`, `slides`, `ui`
  - `.env.example` с ключевыми переменными

## Улучшения (после MVP / optional)

- Презентации:

## Критерии готовности

- `npm run dev -- "..."` возвращает ответ и корректно завершает ReAct.
- `npm run ui` поднимает сервер и:
  - `/` открывает UI
  - `/api/slides` стримит события и корректно прекращает работу при разрыве соединения
  - `/api/run` (или аналогичный) обрабатывает одиночный запрос агента
